# 图片输入与验证记录

2026-08-31：新建居民信息页已接通单张图片输入。支持选择文件、拖拽和粘贴，允许 JPG / PNG / WebP，最大 10 MB；图片可单独提交，也可带补充说明。

## 数据流程

- 选择图片时只在浏览器预览；点击“AI 整理为事项”后才提交。
- `POST /api/intakes` 继续支持原有文字 JSON 请求。图片使用 multipart：`image` 为文件，`metadata` 为 JSON 字符串，包含 `rawText`、`sourceType: "image"`、`organizationId` 和可选 `idempotencyKey`。JSON 包装避免 multipart 改写原文换行。
- 服务端限制请求实际大小、图片类型和文件头。Intake 与 Attachment 在同一事务内保存，重放提交会比较原文和图片内容。
- 本地 MVP 将图片作为 data URL 存入现有 Attachment 表，不写 public 目录、不创建公开文件链接；无需数据库迁移。此方式只适合小规模本地演示，尚无生产级认证、访问控制和留存策略。
- 分析时读取已保存图片，以 OpenAI 兼容的 `image_url` 消息发送给 Qwen/OpenAI。图片和文字均按不可信输入处理，模型输出仍须通过原有结构校验。
- 失败后复用已保存的 Intake；刷新可恢复原图。AI 草稿确认页和手动创建页均可对照原图，最终仍由人工确认是否建档。
- 语音入口禁用并显示“暂未支持”，未实现录音或 ASR。

## 模型配置边界

`GET /api/intakes/capabilities` 只检查本地 Provider 装配，不发送模型请求、不返回密钥。真实 Provider 已配置不代表所选模型一定支持视觉，仍需使用支持图片的模型进行验收。

当前运行环境经检查为 `mock / mock-v1`。Mock 遇到图片会明确失败，不会返回固定演示结果冒充图片识别。启用真实识别需要在本地服务的环境变量中设置 `AI_PROVIDER=qwen` 或 `openai`，以及对应的 API Key 和支持视觉的模型名；更改后重启服务。不要将密钥写进代码或提交到仓库。

## 已完成验证

- AI 包 52 项单元测试通过，含两种 Provider 的图片消息、纯图片、纯文字兼容及 Mock 拒绝图片测试。外部模型响应由测试模拟，不代表真实识别质量。
- Web 包 24 项单元测试通过，覆盖空文件、多文件、伪装图片、超大请求、非法表单及原文换行保留。
- Web TypeScript 检查、AI 包编译通过。
- 本地真实接口验证：图片及文字完整恢复、重复提交复用记录、同一幂等键更换图片返回 409、Mock 失败重试只保留一份原始输入和失败分析记录；未创建正式 Case。接口测试自身生成的数据已清理。
- 浏览器验证：切换图片输入、文件选择与预览、纯图片提交、Mock 错误提示、刷新恢复原图、重试及手动创建页核对原图。

未调用付费模型，未上传私人截图，未运行会重置现有数据库的端到端测试。拖拽和粘贴处理已实现，但上述浏览器验收使用的是文件选择器。
