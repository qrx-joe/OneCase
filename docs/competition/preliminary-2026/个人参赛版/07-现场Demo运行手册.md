# OneCase 现场 Demo 运行手册

服务对象：[06-现场展示脚本-20分钟](06-现场展示脚本-20分钟.md) §2.4 的 Demo 段。目标：**任何一步失败都有下一步，不冷场、不编造、不粉饰。**

本文运行态基线为 2026-09-06 凌晨实测：dev server :3000，`/api/intakes/capabilities` 返回 `stepfun / step-1o-turbo-vision`（`imageModelSupported: true`），Dashboard KPI 待处理 2 / 处理中 3 / 高优先级 3（seed 基线），CASE-018 状态 `IN_PROGRESS`（可直接转"已解决"）。`apps/web/.env.local` 为 `AI_PROVIDER=stepfun`，**未配置 DEMO_MODE / AI_ALLOW_MOCK_FALLBACK 双开关，AI 失败会如实报错、不静默降级**。系统当前带演示虚拟登录（账号 `onecase` / 密码 `onecase2026`，见 `apps/web/src/lib/demo-auth.ts`；登录页页脚有小字备忘）。

纪律：演示只用合成数据；不在演示机写入任何真实居民信息；不把 Mock 说成真实模型；不把候选分数说成重复概率；不声称注入防护。

## 4. 支线：图片链路（真实 StepFun，约 1.5 分钟）

前提：T-1 天合成图片预检已通过。话术开场必须带："**这是现场一次真实输出，不代表识别准确率；质量有独立评估，后面一页给数据。**"

1. 输入页切"截图 / 图片"，选择合成图片 → 核对预览；补充说明选填。
2. 点"AI 整理为事项"（此刻才上传）→ 处理动画（真实调用约 2–6 秒）→ Review。
3. 展示：AI 草稿字段 + **原图对照**入口；缺失字段保持未知。
4. 结束语："链路已通；准确率、稳定性靠代表性样本验收，我做了 30 次真实调用的独立评估，结果下一页如实汇报。"

**预检未通过或现场失败**：只展示"选择 → 预览 → 上传保存 → 刷新恢复 → 转人工/手动创建"，如实说"真实识别此刻不可用，我不会假装它成功了"。**严禁**把 Mock 拒绝图片、能力接口返回、或一次历史成功记录说成现场识别成功。

## 5. 支线：容错兜底（约 1 分钟）

任选其二（时间不够就口述 + 指 PPT P7）：

1. **草稿可改**：主线 #7 已覆盖，此处一句话回收。
2. **重复确认被拒**：对已确认的 Intake 再次提交确认 → `INTAKE_ALREADY_CONFIRMED`。现场操作路径有限，建议**口述 + 出示 web 包幂等测试证据**，不做即兴操作。
3. **AI 失败兜底**（若主线真的失败了，顺势变成正式演示）：输入保留 → 重试一次 → 仍失败则转"手动创建事项"，原始反馈自动挂为居民来源。话术："大家看到的正是设计内的失败路径：输入不丢，流程不断，AI 不是单点。"

## 6. 故障预案（症状 → 处置）

| 症状 | 处置 | 话术 |
|---|---|---|
| 点"AI 整理"长时间无响应 | 等待 10 秒 → 重试 1 次（重试复用记录，不重复建档） | "真实模型调用中，稍等" |
| AI 明确报错 | 停止重试；直接走 §5.3 手动创建演示 | "AI 失败是设计内的场景：输入保留、可手动兜底" |
| 想切 Mock 救场 | **默认不切**。仅当流程无法继续：设 `DEMO_MODE=true` + `AI_ALLOW_MOCK_FALLBACK=true` 并重启服务，且**开场即声明**"真实模型现场不可用，已切 Mock，只演示操作流程，图片转人工" | 诚实本身就是加分项 |
| 页面 500 / 热重载异常（webpack 缓存） | 重启 `pnpm --filter @onecase/web dev`（约 30–60 秒），期间切 P8 讲架构 | "趁重启讲一下分层：模型建议与业务规则分离" |
| 候选/KPI 与本手册不符 | **以页面为准**，用通用话术（"当前库的实际输出"），不硬凑 CASE-018/011 | — |
| 演示库被污染（数字明显不对） | `db:reset` 后重走主线（预留 2 分钟，仅在确认是演示库时） | — |
| 投屏黑屏/分辨率异常 | 换转接头 → 不行则播备份录屏（口播同步讲解） | "为稳妥我准备了录屏，讲解不变" |
| 现场断网 | 图片链路必挂；真实模型主线同样受影响 → 切录屏或走手动创建演示 | — |
| 时间被挤占 | 16:30 止损点：直接跳 P14 收束词 | 见 06 脚本弹性规则 |

## 7. 现场红线（不得说 / 不得做）

1. 不报准确率、召回率、提效百分比——没有实测数据，一个数都不给。
2. 不声称"防提示注入""安全已加固"——评估结论只支持"一轮缓解在 1 个正式样本 + 3 个变体上有效"。
3. 不把 Mock 输出、历史成功记录、能力接口返回说成"现场识别成功"。
4. 不把候选分数说成"重复概率 XX%"——它只是未校准的排序分。
5. 不把演示库统计说成"社区使用成绩"。
6. 不操作语音入口（已禁用）；不承诺微信接入时间表。
7. 不现场演示 `db:reset` 作为节目环节，更不对非演示库执行。
8. 说"测试 213 项"必须带日期口径（2026-09-06 复跑；PPT P9 提交版快照仍为 200，答辩口播以最新实测为准并说明材料定格后代码仍在演进），不说"永远通过"。
9. 屏幕与讲稿不出现姓名、电话（报名资料已含）。
10. "下一步会做"的承诺收窄到 06 脚本 §2.6 已列范围，不现场加码。
