## 二、样表脱敏操作规则（收集台账/迎检模板时执行）

| 原始字段 | 处理方式 |
|---|---|
| 居民姓名 | 保留姓氏，名字改"某"（张某某）；或直接删列 |
| 联系电话 | 保留前 3 后 4（138\*\*\*\*5678），或删列 |
| 身份证号 | 一律删除 |
| 精确门牌号 | 楼栋单元保留，室号改"××室" |
| 诉求正文中的姓名/号码 | 替换为"居民A/居民B" |
| 照片/截图 | 人脸、车牌、屏幕通知栏打码或裁剪 |
| 经办人签名 | 替换为工号或"经办1" |

**操作步骤**：
1. 当场拍照仅作脱敏底稿（对方同意的前提下），当天完成脱敏；
2. 脱敏后文件存 `docs/research/ledger-samples/<来源编号>-<类型>.xlsx`（如 `S1-台账-2026-09.xlsx`）；
3. 在同目录 `README.md` 登记每份样表：来源编号、字段清单、用途备注——**登记文件本身不含任何个人信息**；
4. 原始未脱敏照片当天从手机与相机删除；如确需保留底稿，仅存本地加密盘且不入仓库。

**自查**：提交前全文搜索手机号格式（1\d{10}）与身份证格式，命中即未脱敏干净。
