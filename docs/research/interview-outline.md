# 访谈提纲（S0-T1）

- **对象**: 一线社区工作人员 / 网格员（社区负责人可选加分项）
- **时长**: 40-60 分钟
- **方式**: 半结构化。问题按序推进，追问按需展开；答案记要点不记全文。
- **记录规则**: 参与人用编号（P1…P5）；涉及真实居民的细节当场模糊化（"某栋某户"）。

> 使用说明：每题下方【追问】是需要挖下去的点，【记录】是填表要点。时间不够时优先保 A2、B4、B6、E1（渠道占比、现行流程、催办、语音）四题——它们直接决定产品走向。

## A. 背景与信息渠道（约 8 分钟）

**A1. 请简单说说您的工作**——负责几栋/多少户？一天大概处理几件居民反映的事？

【记录】负责范围、日均/周均件数。

**A2. 居民找您的渠道有哪些？**微信文字、微信语音、电话、上门、其他（网格群/物业转来）。

【追问】让 TA 给这些渠道按"数量"排个大概比例；再按"费时间"排一次。两个排序不一致的地方重点问为什么。
【备选方法】比例答不上来很正常——请 TA 掏出手机翻**最近 10 条**居民聊天，现场数：几条文字、几条语音、几个电话。数出来的比估的准得多。
【记录】比例 + 两个排序 + 实数法结果（若有）。

**A3. 最高频的三类诉求是什么？**最难处理的一类是什么？

【追问】有没有哪类诉求让您觉得"这不该找我/落不进我的本子"？——这是类别字典是否够用的直接证据。
【记录】频次排序；"落不进"的例子原话。

## B. 现行流程（约 20 分钟，本包核心）

**B1. 完整走一遍**：上周某条具体的居民反映（TA 现场回忆），从"居民开口"到"这事办完"，中间经过了哪些步骤？每一步用什么记？（脑子/纸质本/手机备忘录/Excel/微信群/政务系统）

【备选】记不清上周的很正常——改问"最近印象最深的一次，哪怕是一个月前的"。
【追问】每步在哪个设备上做？要切换几次应用？哪些步骤是"回头补"的（当时没记，事后凭记忆补）？手机上有多少个**工作群**？（群的个数是现状复杂度最便宜的指标）
【记录】逐步流程链 + 每步工具 + 切换次数 + 补录环节 + 工作群数。

**B2. 登记之后**：这个事怎么到处理人手上？（自己办 / 发群里 @人 / 电话通知 / 报上级）分派的依据是什么？

【记录】分派方式与依据字段（地点？类别？责任单位？）。

**B3. 同一类事反复发生时**（比如同一盏灯第三次坏），您怎么发现"这是老问题"？

【追问】靠记忆？翻聊天记录？翻台账？找不到过吗？
【记录】查重现状 + 找不到的实例。

**B4. 催办**：怎么发现一件事拖太久了？靠什么提醒自己？（备忘录？群里催？上级催？）

【追问】最近一次"发现时已经拖了很久"的事是什么？拖了多久、谁发现的？
【记录】催办机制 + 沉底实例。

**B5. 回访与办结**：办结怎么记录？居民满意不满意记不记？记在哪？

**B6. 迎检材料**：多久做一次？什么格式（Excel/Word/打印）？从哪份数据整理？最费时的是哪一步？（所在社区没有迎检任务的，此题跳过，改问"您定期要向上交什么数字/报表？"）

【追问】"如果材料能自动生成就好了"——TA 信不信？最怀疑什么？
【记录】频率、格式、费时点。

## C. 重复与合并（约 5 分钟）

**C1. 五个居民分别反映同一栋楼的同一个问题**，理想情况应该记一条还是五条？现在的实际情况是什么？

【追问】实际发生过"同一件事立了三个案"吗？后果是什么（返工？上级追问？）。反过来，"把两件不同的事当成一件"发生过吗？
【记录】理想口径 vs 实际操作 + 双向错误实例。

## D. 返工与痛点（约 5 分钟）

**D1. 最近一次"记录出了问题"**——漏记了、找不到了、写错了、格式不对被打回——具体说说。

【记录】错误类型 + 修复成本（花多久、什么后果）。

**D2. 如果只能改进一个环节**，您选哪个？录入、找重复、催办、回访、材料整理——为什么？

【记录】排序第一的环节。**这题答案与计时数据（S0-T2）对照，是 Gate 0 的主判据。**

## E. 语音必答题（约 3 分钟，不许跳过）

**E1. 微信语音和电话占您接收信息的比例大概多少？**这些语音后来怎么变成文字记录的？谁转写？转一条大概多久？错得多吗（方言、老年人表达）？

【追问】如果有工具能把语音自动变成文字草稿（错误需要您核对），您觉得值不值？顾虑是什么？
【记录】语音占比 / 转写耗时 / 价值判断。**这题决定 ASR（语音转写）是否立项。**

## F. 数据边界与接受度（约 5 分钟）

**F1. 居民的哪些信息您觉得"不该进"手机里的工具？**姓名？电话？照片？有没有单位明文规定？

【记录】红线清单 → 反哺试点授权边界备忘（S0-T5）。

**F2. 一个新工具要满足什么，您才会真的用它？**（多选追问：不增加步骤 / 手机上能用 / 上级认可 / 数据安全承诺 / 免费 / 替我记录就行不用我学）

【记录】接受条件排序。

---

## 访谈后 24 小时内要做的

1. 整理记录成 `interviews/<日期>-P<n>.md`：按题目归档原话要点，标注【事实】与【观点】。
2. 把 A2 比例、D2 排序、E1 占比三组数据抄进 [time-baseline-template](./time-baseline-template.md) 的汇总区。
3. 对照既有假设列"被证实 / 被推翻 / 意外发现"三栏，意外发现单独记——它们往往是真需求。
